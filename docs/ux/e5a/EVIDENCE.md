# E5A — Evidence index

Actual application screenshots only. Concept images are described separately in REFERENCES.md. Raw capture status is PARTIAL until semantic/visual acceptance, FAIL on observed browser errors/overflow, and BLOCKED where the named destination is absent.

The base matrix contains 26 sections × 2 variants × 3 viewports = 156 records, including six clearly labelled related-only Connected Accounts captures for the absent Connected Services section. There are 34 additional material, inspector, server and companion cases (190 records total), plus 18 layout probes. Each record has a viewport PNG; some also have a full-panel PNG.
