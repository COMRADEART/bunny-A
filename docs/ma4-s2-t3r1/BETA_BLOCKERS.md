# MA4-S2-T3R1 — Explicit Beta Blockers (`BETA_BLOCKERS.md`)

Per the T3R1 exit gate (*"Reliability, accessibility and Planner behavior are either qualified or recorded as explicit beta blockers. Do not suppress a blocker to proceed to public release"*), the following explicit blockers prevent general public beta release at the close of T3R1 (`2026-10-24`):

| Blocker ID | Category | Severity | Description & Evidence | Required Closure Action (Target Milestone) |
|---|---|---|---|---|
| **BLK-T3R1-01** | **24-Hour Real-Clock Candidate Soak (`R1-G2`)** | **High (Release Gate)** | Original T3R Soak A (`e6b6645`, `16.65 h`) failed `S5_memory` (`156.0–208.9 MB/day`) and `S9_permissions` (`cancelledWorkRan: 1` harness timing race). Candidate Soak B (`448ca6b`, port `43192`) is passing `S5_memory` at **`43.7 MB/day`** (`<= 50 MB/day`) and all active criteria at `3.08 h`, but does not complete 24 real hours until `~2026-10-25 15:06 UTC` ([`SOAK_FINAL_VERDICT.md`](SOAK_FINAL_VERDICT.md)). | Allow Soak B to complete 24 real-clock hours (`T7-D / T8-F`) and verify `soak-report.mjs` reports `PASS` on `S1`–`S12`. |
| **BLK-T3R1-02** | **7B Planner / Reviewer Functional Completion (`R1-G6`)** | **High (Model Quality)** | Pin-derived JSON Schema (`61673e2`, `4dd1d43`, `713891e`) raised `qwen2.5-coder:7b` schema-valid plans from `0/5` to `5/5` (`100%`) and passed `8/8` (`100%`) adversarial prompt-injection tests (`X1`–`X8`), but functional accuracy on held-out `H1`–`H5` is **`2/5` (`40%`)** and end-to-end task completion is **`1/5` (`20%`)** (`H2`/`H4` missing `fromSteps`, `H5` placeholder title, `H1` Reviewer over-rejection of `file.stat`; `deepseek-r1:7b` 90 s timeout under grammar-constrained `<think>`) ([`REAL_MODEL_VALIDATION.md`](REAL_MODEL_VALIDATION.md)). | Improve Planner prompt / `fromSteps` repair and Reviewer `file.stat` contract, and support two-pass or non-grammar extraction for thinking models (`T5 / T8`). |
| **BLK-T3R1-03** | **Goal Criterion Linking in Dashboard UI (`R1-G9` Journey A)** | **Medium (Product UX)** | While the Host (`goal.evaluate`) advances goal criteria only from completed tasks linked by `goalId` and `criterionId` with verified receipts, the Tasks dashboard UI (`proactive.tsx`) lacks a selector to link a task or schedule to a goal criterion (`Journey A: PARTIAL` in [`END_TO_END_USER_JOURNEYS.md`](END_TO_END_USER_JOURNEYS.md)). | Add Goal & Criterion linking controls to task/schedule creation in `proactive.tsx` (`T5`). |
| **BLK-T3R1-04** | **Windows Narrator Per-Row Button Context & Live Announcements (`R1-G4`)** | **Medium (Accessibility)** | Live Windows Narrator testing (`Rounds 1–4`) found: (1) per-row action buttons (`Dismiss`, `Snooze 1 h`, `Pause`, `Turn off`, `Approve`, `Cancel`, `Approve this action`, `Deny`, `Inspect details`) lack item-title context in their accessible names, and (2) asynchronous task completion and monitor `source_changed` updates were not spoken unprompted in Round 4 ([`WINDOWS_NARRATOR_QUALIFICATION.md`](WINDOWS_NARRATOR_QUALIFICATION.md)). | Add item-specific `aria-label` attributes to per-row buttons and assertive/polite live-region announcement wiring (`T5`). |
| **BLK-T3R1-05** | **Physical Android TalkBack Live Pass (`R1-G5`)** | **Medium (Hardware Gate)** | The physical Samsung SM-S948U (`com.routeragent.jev` `2.1`) was disconnected (`adb devices` empty) during T3R1, leaving live TalkBack touch exploration `NOT TESTED` ([`ANDROID_TALKBACK_QUALIFICATION.md`](ANDROID_TALKBACK_QUALIFICATION.md)). | Connect Samsung SM-S948U via USB and complete live TalkBack touch-exploration qualification (`T5 / T8`). |
