# Bunny A

A local-first AI workstation for Windows, with an Android companion.

- **Runs on your PC.** Local models through Ollama; cloud models only if you add a key. Nothing is sent to the developer.
- **You approve what matters.** Actions with consequences wait in the Approval Center on your PC.
- **Your phone as a remote.** Pair the Android app with a one-time code to follow tasks and send prompts over HTTPS.

## Install

- **Windows 10/11:** Microsoft Store (coming with the public beta).
- **Android 8+:** Google Play (coming with the public beta).
