# Security policy

Please **do not** report security problems in public issues.

Report them privately through GitHub: **Security → Report a vulnerability** on
https://github.com/COMRADEART/bunny-A. Include the version (Settings → About), what you did, and what happened.
You will get an acknowledgement within 7 days.

In scope: the Windows Host and client, the Android companion, pairing and remote access, approvals, and the installers.
