# T8 information architecture

Primary navigation: Home, Agentic, Projects, Activity, Models, Devices, Settings. Bunny chat is a separate destination. Agentic owns persistent Agent presentation, accepted Mission plan, permissions, activity and results. UI focus IDs select canonical entities; no Agent, Mission, Task, registry, authorization or event authority is created in the client. Project → Agent/Mission links preserve IDs. Current Task links use accepted Mission step.taskId.

Home provides actual counts and verified Mission results, with unknown counts while loading. Models presents T1 discovery and T2 usage; existing T3 Task detail owns selection explanations. Devices retains paired-device controls and explicitly limits physical-phone claims. Settings retains Host-backed settings; web Appearance exposes only theme and motion. Native-only preferences remain in the existing native menu.
