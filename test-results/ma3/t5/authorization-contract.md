# T5 authorization contract

AgentRuntime → MissionManager → existing canonical MA0 decision/providerScopeViolation → TaskManager or Capability Bus → existing adapters → verification/checkpoint.

The adjunct records reviewed intent and finite accounting, never a bearer credential or competing grant engine. Host-owned canonical authorization id, HMAC-protected revisioned scope, current Agent/Mission/project/step and execution generation must all agree. Persistent deny/read-only rules win; forged oneTime/direct flags have no authority. BEGIN IMMEDIATE rereads current evidence and calls canonical validation before adding an admission. Attempts consume allowance even when they fail; retries/reroutes receive fresh admission, never a reset.

Root identity and canonical paths are rechecked. Terminal supports exact pure Node checks only, with a positive parser grammar and copied inputs, minimal environment, IR-H1 process ownership, script/executable hashes and bounded time. The Node permission flag is defense in depth and is not an arbitrary-code sandbox. Git reads disable configured execution helpers. Broader CLI/provider tool sessions, arbitrary browser scopes, publishing, installation, credentials and external communications are not automatically delegated.

Restart preserves historical consent/admission evidence, marks unresolved old effects UNKNOWN and discards execution generation. Fresh reviewed canonical consent creates a new MA0 envelope; interrupted/ambiguous effects still need explicit retry review. Remote clients may only accept an existing id/revision offer; they cannot propose or adjust scope. Stop/revoke persists before cancelling existing work. Already admitted effects remain recorded.

Evidence classifications are in adversarial-matrix.json. The model-path proof uses real TaskManager admission with simulated provider I/O, not live model service success.

The Windows native package includes an unchanged MIT-licensed Acorn 8.18.0 parser; the closure and imports were checked without node_modules. Generic Vercel preview lacks trusted TCP peer metadata and refuses owner access; the desktop build uses the actual installed gateway's Node HTTP adapter. No authentication fallback to Host headers was added.
