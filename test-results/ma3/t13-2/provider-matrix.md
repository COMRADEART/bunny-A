Sign in with ChatGPT identity/delegated plan sharing requires official client eligibility/registration. Bunny holds no client registration; these modes are unsupported. No client ID, callback, partner approval or vendor token was fabricated. Metadata authentication never verifies inference entitlement. No subscription was purchased, billing enrolled, key imported from another app or browser credential extracted.

Native binaries are discovered through configured executables and read-only supported status/version commands. This release does not independently verify Authenticode signatures, WSL profiles or every managed/custom-gateway configuration. API checks use fixed HTTPS hosts, redirect refusal, certificate verification, capped response reads and timeouts. A failed or unknown check cannot enable Tasks.
