# Durable Agent workspace contract

`agent_workspaces` is subordinate Host metadata, not a new workflow or permission authority. Unique Agent and Mission bindings identify one durable workspace. Records pin Project (nullable), configured workspace identity, owned root/scratch identity, READY/CONTEXT_CHANGED, creation/use timestamps, 64 MB ceiling, owner UUID and manifest revision. Layout: configured `workspace/agents/<agent UUID>/<Mission UUID>/scratch`, with a fixed manifest and ownership marker. Explicitly created Projects use `workspace/projects/<UUID>`.

Installed Hosts require the canonical `BUNNY_HOST_WORKSPACE` supplied by the existing launcher; explicit startHost options are available for tests. Non-installed Hosts derive their isolated workspace under their actual data directory. Standalone legacy AgentRuntime constructors use Mission state/workspace, not a user's Project root. No username-specific path is used by runtime source.

Atomic staging/rename plus transactional unique row publication refuses collisions. Failed/orphan staging is preserved and never automatically adopted or deleted. Admission/recovery checks canonical paths, ancestor symlinks/junctions, pinned directory identity, ownership marker and manifest hash. UNC/device/ADS/reserved/trailing-dot paths fail closed. Relative containment checks reject prefix cousins. Hard-linked files are excluded. Scratch traversal is bounded to 1000 entries, depth 12 and 64 MB including proposed writes. Unknown/changed workspaces stop admission and become CONTEXT_CHANGED; recovery records INTERRUPTED for review.

User roots, Agent scratch, approved worktrees and existing artifact storage are separate domains. Another Agent cannot enter scratch through Project registration or current Mission access. Existing WorkspaceCoordinator shared/exclusive locks protect overlapping roots; there is no second scheduler. No T7 cleanup deletes a workspace or arbitrary user path: cleanup always refuses pending a separate reviewed operation. Archive does not clean or restart work.
